# LAB 3.5 – Extended Device Compliance

## Goal

The goal of this lab is to extend **device compliance policies** beyond Windows by configuring and validating **compliance for mobile devices**.

This ensures that all device platforms meet minimum security requirements before accessing corporate resources.

---

## Why This Matters

In a modern workplace, users access data from multiple device types.

Without extended compliance:
- Mobile devices may bypass security standards
- Access decisions are inconsistent across platforms
- Zero Trust enforcement is incomplete

Device compliance must be **consistent across all device types**.

---

## What Was Implemented

During this lab, the following configurations were applied:

- Creation of compliance policies for:
  - iOS devices
  - Android devices (Work Profile)
- Definition of security requirements such as:
  - Device integrity
  - OS version requirements
  - Basic security settings
- Assignment of policies to the appropriate user and device groups

These policies complement existing Windows compliance requirements.

## Validation

The extended compliance setup was validated by:

- Syncing mobile devices with Intune
- Reviewing compliance status per platform
- Identifying compliant and non-compliant devices
- Confirming consistent reporting across device types

---

## Key Concepts Applied

- Cross-platform device compliance
- Consistent security baselines
- Device trust across operating systems
- Input for Conditional Access decisions

---

## Result

At the end of this lab:

- Compliance policies apply across Windows, iOS, and Android
- Device trust is evaluated consistently
- Non-compliant devices are clearly identified
- The Zero Trust device foundation is strengthened

This lab ensures that **all supported device platforms meet security expectations**.
