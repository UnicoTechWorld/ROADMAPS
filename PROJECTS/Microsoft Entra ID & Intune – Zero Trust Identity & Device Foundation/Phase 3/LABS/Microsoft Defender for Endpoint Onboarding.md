# LAB 3.8 – Microsoft Defender for Endpoint Onboarding

## Goal

The goal of this lab is to **integrate Microsoft Defender for Endpoint (MDE)** with Microsoft Intune in order to gain **centralized visibility and protection** of endpoint security.

This enables advanced threat detection and prepares the environment for **risk-based access decisions**.

---

## Why This Matters

Without endpoint threat visibility:
- Security teams cannot detect compromised devices
- Device trust is based only on configuration, not on real threats
- Access decisions lack real-time risk context

Microsoft Defender for Endpoint provides **continuous endpoint protection and monitoring**.

---

## What Was Implemented

During this lab, the following configurations were completed:

- Activation of Microsoft Defender for Endpoint
- Integration between Intune and Defender for Endpoint
- Configuration of automatic onboarding for Windows devices via Intune
- Verification that devices report to the Defender security portal

This ensures that managed devices are **continuously monitored for threats**.

## Validation

The Defender onboarding was validated by:

- Confirming device visibility in the Defender portal
- Verifying onboarding status from Intune
- Reviewing device security status and health
- Ensuring telemetry is correctly received

---

## Key Concepts Applied

- Endpoint Detection and Response (EDR)
- Intune ↔ Defender integration
- Centralized endpoint security visibility
- Foundation for risk-based security decisions

---

## Result

At the end of this lab:

- Devices are onboarded into Defender for Endpoint
- Endpoint threats are visible centrally
- Security posture can be assessed in real time
- The environment is ready for advanced endpoint protection

This lab adds **real-time threat intelligence** to the Zero Trust device model.
