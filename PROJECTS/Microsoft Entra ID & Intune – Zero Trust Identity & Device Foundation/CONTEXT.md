# Microsoft Entra ID & Intune – Zero Trust Identity & Device Foundation Project

This repository contains a **hands-on learning and implementation project** around **Microsoft Entra ID** and **Microsoft Intune**, focused on building a **secure identity and device foundation** aligned with **Zero Trust principles**.

The project simulates real-world work performed by a **Junior / Medior Modern Workplace or Identity Engineer**, covering identity foundation, Conditional Access, device compliance, and Microsoft Defender for Endpoint integration.

---

## Project Scope & Focus

This project focuses on three core areas:

- **Identity foundation** in Microsoft Entra ID  
- **Device management and compliance** using Microsoft Intune  
- **Conditional Access enforcement** using device and identity signals  

> Governance and advanced lifecycle automation are intentionally **out of scope** for this project.

---

## Project Structure Overview

### **Phase 1 – Identity Foundation** *(Completed)*

**Focus:**
- User and group structure  
- Security groups & access modeling  
- Group-based licensing  
- MFA & Self-Service Password Reset (SSPR)  
- Privileged role separation (break-glass accounts)  
- Internal users and external guest access  


---

### **Phase 2 – Conditional Access** *(Completed)*

**Focus:**
- Conditional Access policy design  
- MFA enforcement for cloud applications  
- Require compliant devices for access  
- Combining identity and device signals  
- Break-glass exclusions and safe rollout practices  



---


### **Phase 3 – Device Identity, Compliance & Security** *(Completed)*

**Focus:**
- Microsoft Intune device enrollment (Windows, Android, iOS)  
- Compliance policies and device state evaluation  
- App protection policies (MAM)  
- Integration between Intune and Conditional Access  
- Microsoft Defender for Endpoint onboarding  
- Using Defender signals in access decisions
