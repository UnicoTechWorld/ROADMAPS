# LAB 5 – Department & Employee Onboarding Flow

## Goal

The goal of this lab is to validate the **end-to-end onboarding process** for a new employee using the identity structure and security controls implemented in previous labs.

This lab ensures that onboarding is **repeatable, consistent, and secure**.

---

## Why This Matters

Without a standardized onboarding flow:
- Users receive inconsistent access
- Licenses are forgotten or misconfigured
- Security settings vary per user
- Manual errors increase over time

A structured onboarding flow reduces operational effort and improves security posture.

---

## What Was Implemented

A realistic onboarding scenario was simulated:

- Creation of a new employee account
- Assignment of user attributes (department, role)
- Addition to the correct security groups
- Automatic license assignment via group membership
- Enforcement of MFA and SSPR at first sign-in
- Administration performed without Global Administrator rights

---

## Key Concepts Applied

- Identity lifecycle management
- Group-based access control
- Automated licensing
- Secure-by-default onboarding
- Least-privilege administration

---

## Result

At the end of this lab:

- New users are onboarded in a predictable and secure way
- Access and licensing are applied automatically
- Security policies are enforced by default
- The onboarding process is scalable and repeatable

This lab confirms that the **identity foundation works as designed** in a real-world scenario.
